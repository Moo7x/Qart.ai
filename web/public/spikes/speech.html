Spike S2: can the agent speak, listen and stop when interrupted?

Uses the browser's Web Speech API (no server, no paid service). Results feed the agent's voice mode (docs/PLAN.md §4.9: voice off by default, text always available).

Support
    1. Speak a long explanation (about 20 s)
    2. Listen (asks for microphone permission)
    3. Interrupt: start speaking and listening together, then talk over it. Expected: speech stops as soon as the browser detects your voice.
    4. Stop: cancels speech, listening and the queued agent actions.
    queued actions: 0
