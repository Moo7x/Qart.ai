Spike S1: can the on-screen agent open tabs?

Each test calls window.open in a different situation and records whether the browser allowed it (window.open returns null when blocked). The target is a public page (the UN SDG 4 page). Results feed the agent's execution contract (docs/PLAN.md §4.9).

A. Inside a user click (expected: allowed)
B. No user gesture: 6 s after a click (transient activation has expired; expected: blocked)
C. On page load, no click at all (expected: blocked) — runs once when the page opens.
D. Agent card pattern: the agent proposes an action; the user clicks its card.

Agent: "I found the official SDG 4 targets page. Open it?"

E. Blocked fallback: when a tab is blocked, show a link the user can click.
